## معرفی

پیدا کردن یک **بورسیه تحصیلی کاملاً فاند‌شده** یعنی باز کردن ده‌ها وب‌سایت با ساختار و شرایط متفاوت. **ایجنت بورسیه دارا** یک **موتور جستجوی بورسیه و ایجنت هوش مصنوعی** است که این کار را برای شما انجام می‌دهد:

1. صدها بورسیه را از وب‌سایت‌های معروف در چند ثانیه **وارد می‌کند** (بدون هوش مصنوعی و بدون نیاز به API key)،
2. با **Gemini و جستجوی گوگل** بورسیه‌هایی را که آن سایت‌ها ندارند پیدا می‌کند،
3. صفحه هر بورسیه را با هوش مصنوعی می‌خواند و **تأمین مالی، ملیت‌های مجاز، رشته‌ها و شرط زبان** را کامل می‌کند،
4. و همه را بر اساس **مقطع، کشور، رشته، تأمین مالی، مهلت و ملیت خودتان** فیلتر می‌کند. همه چیز روی کامپیوتر خودتان ذخیره می‌شود.

<a id="features"></a>

## امکانات

- 🎨 رابط کاربری مدرن با هدر، منوی کناری، آمار زنده، کارت‌های بازشونده و **تصویر شاخص (نماد معروف) برای هر کشور مقصد**
- 🌍 نمایش بورسیه‌ها به تفکیک مقطع: لیسانس، ارشد، دکتری، پسادکتری و سایر
- 🔎 فیلتر کشور، رشته یا کلیدواژه، نوع تأمین مالی، حذف مهلت‌های گذشته و **واجد شرایط بودن بر اساس ملیت** (هر کشوری قابل انتخاب است)
- 📚 دریافت سریع از وب‌سایت‌ها: Scholars4Dev، ScholarshipTab، ScholarshipSet و سایت‌های آلمان، بریتانیا، کانادا، آمریکا و استرالیا
- 🤖 جستجوی هوشمند وب با Gemini؛ اگر کشورها را خالی بگذارید، در **همه کشورها** جستجو می‌شود
- ✨ تکمیل اطلاعات بورسیه‌ها با خواندن صفحه رسمی‌شان
- 🗣️ رابط چهار زبانه (انگلیسی، فارسی، ترکی، عربی) با پشتیبانی کامل راست‌به‌چپ و فونت ایران‌سنس؛ زبان انتخابی بعد از رفرش حفظ می‌شود
- 💾 ذخیره محلی در SQLite و خروجی CSV
- 🛡️ تلاش مجدد خودکار هنگام خطای 503 و رفتن به مدل جایگزین هنگام خطای سهمیه (429)

<a id="quick-start"></a>

## شروع سریع

**پیش‌نیاز:** Python نسخه ۳.۱۰ تا ۳.۱۴ (ترجیحاً ۳.۱۲ یا ۳.۱۳) (از [python.org](https://www.python.org/downloads/)؛ در ویندوز هنگام نصب گزینه **Add Python to PATH** را تیک بزنید) و یک کلید API رایگان Gemini (فقط برای بخش‌های هوشمند). نسخه‌های بسیار جدید مثل ۳.۱۵ هنوز پشتیبانی نمی‌شوند (برخی وابستگی‌ها برایشان پکیج آماده ندارند). یکی از دو روش نصب را انتخاب کنید:

<a id="install-direct"></a>

### روش ۱: نصب مستقیم (بدون Git)

1. صفحه پروژه را در GitHub باز کنید، روی دکمه سبز **Code** و سپس **Download ZIP** بزنید.
2. فایل ZIP را در یک پوشه دلخواه Extract کنید (مثلاً `Documents/dara-scholarship-agent`).
3. برنامه را اجرا کنید:
   - **ویندوز:** روی فایل **`Run (Windows).bat`** دوبار کلیک کنید.
   - **مک / لینوکس:** در ترمینال داخل پوشه، دستور `bash "Run (Mac).sh"` را بزنید.

   در اولین اجرا، محیط مجازی ساخته می‌شود، وابستگی‌ها نصب می‌شوند، فایل `.env` ساخته می‌شود و برنامه روی **http://localhost:8501** باز می‌شود. اجراهای بعدی چند ثانیه طول می‌کشند.
4. کلید API را در برنامه (بخش **Settings** در سایدبار) یا در فایل `.env` وارد کنید.

> برای به‌روزرسانی، ZIP جدید را دانلود کنید و فایل‌ها را روی پوشه قبلی کپی کنید. فایل‌های `.env` و `scholarships.db` را نگه دارید.

<a id="install-git"></a>

### روش ۲: نصب با Git (مناسب برای به‌روزرسانی و مشارکت)

</div>

```bash
git clone https://github.com/idanieldara/dara-scholarship-agent.git
cd dara-scholarship-agent
```

<div dir="rtl">

سپس با `Run (Windows).bat` (ویندوز) یا `bash "Run (Mac).sh"` (مک / لینوکس) اجرا کنید، یا دستی:

</div>

```bash
python -m venv venv
venv\Scripts\activate            # ویندوز  |  مک/لینوکس: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env           # ویندوز  |  مک/لینوکس: cp .env.example .env
streamlit run app.py
```

<div dir="rtl">

هر زمان با `git pull` به‌روزرسانی کنید. اسکریپت‌های اجرا وابستگی‌های تغییرکرده را خودکار نصب می‌کنند؛ در اجرای دستی دوباره `pip install -r requirements.txt` را بزنید.

> **اگر Streamlit در اولین اجرا ایمیل خواست:** فقط **Enter** بزنید. فایل‌های `Run (Windows).bat` و `Run (Mac).sh` این سؤال را خودکار رد می‌کنند. برنامه را همیشه از داخل پوشه پروژه اجرا کنید.

<a id="launcher"></a>

### استفاده از اسکریپت اجرای یک‌کلیکی (`Run (Windows).bat` / `Run (Mac).sh`)

فایل `Run (Windows).bat` (ویندوز) و `Run (Mac).sh` (مک / لینوکس) برنامه را بدون تایپ هیچ دستوری اجرا می‌کنند. در هر بار اجرا:

1. اگر پوشه `venv` نباشد، محیط مجازی را می‌سازند (فقط بار اول)،
2. بررسی می‌کنند همه وابستگی‌ها نصب و به‌روز باشند،
3. اگر `.env` نباشد، آن را از `.env.example` می‌سازند،
4. سؤال ایمیل اولین اجرای Streamlit را رد می‌کنند،
5. دستور `streamlit run app.py` را اجرا می‌کنند و برنامه روی **http://localhost:8501** باز می‌شود.

**در ویندوز**

1. مطمئن شوید Python نسخه ۳.۱۰ تا ۳.۱۴ (ترجیحاً ۳.۱۲ یا ۳.۱۳) نصب است (هنگام نصب گزینه **Add Python to PATH** را تیک بزنید).
2. پوشه پروژه را باز کنید و روی **`Run (Windows).bat` دوبار کلیک کنید**.
3. یک پنجره سیاه (Command Prompt) باز می‌شود. اجرای اول چند دقیقه طول می‌کشد چون پکیج‌ها نصب می‌شوند؛ دفعه‌های بعد فقط چند ثانیه.
4. وقتی برنامه آماده شد، مرورگر باز می‌شود. اگر باز نشد، آدرس **http://localhost:8501** را خودتان وارد کنید.

**در مک / لینوکس:** در ترمینال داخل پوشه پروژه دستور `bash "Run (Mac).sh"` را بزنید.

> **نکات مهم**
> - تا وقتی از برنامه استفاده می‌کنید، پنجره سیاه را باز نگه دارید. بستن آن (یا `Ctrl + C`) برنامه را متوقف می‌کند.
> - اگر پیام *No supported Python found* دیدید، Python نسخه ۳.۱۲ یا ۳.۱۳ را نصب کنید و تیک **Add Python to PATH** را بزنید.
> - کلید API Gemini را در برنامه (بخش **Settings** در سایدبار) یا در فایل `.env` (`GEMINI_API_KEY=...`) وارد کنید.
> - ترجیح می‌دهید از ترمینال استفاده کنید؟ دستورهای دستی «روش ۲» دقیقاً همین کار را می‌کنند.

<a id="api-key"></a>

### دریافت کلید API

1. به <https://aistudio.google.com/api-keys> بروید.
2. با اکانت Google (@gmail.com) وارد شوید؛ اگر اکانت ندارید، از شما خواسته می‌شود بسازید.
3. روی **Create API key** کلیک کنید.
4. یک نام برای کلید وارد کنید و روی **Create key** بزنید.
5. روی نام کلید (زیر ستون **Key**) کلیک کنید، کلید را کپی کنید و در فایل `.env` (به‌صورت `GEMINI_API_KEY=...`) یا در کادر سایدبار برنامه وارد کنید.

> بخش «دریافت از وب‌سایت‌ها» بدون کلید API هم کار می‌کند.

<a id="configuration"></a>

### پیکربندی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `GEMINI_API_KEY` | ندارد | کلید Google AI Studio (یا در سایدبار وارد کنید) |
| `GEMINI_MODEL` | `gemini-2.5-flash` | مدل اصلی |
| `GEMINI_FALLBACK_MODEL` | `gemini-2.5-flash-lite` | مدل جایگزین هنگام شلوغی یا پر شدن سهمیه |

<a id="usage"></a>

## نحوه استفاده

1. از بخش **Settings** در سایدبار، زبان، **ملیت**، مدل و API key را تنظیم کنید و با منوی سایدبار بین «جستجوی بورسیه» و «نتایج ذخیره‌شده» جابه‌جا شوید.
2. بورسیه‌ها را جمع کنید: «دریافت از وب‌سایت‌ها» یا «جستجوی هوشمند وب».
3. با تب‌های مقطع و فیلترها نتایج را مرور کنید.
4. در صورت نیاز، «تکمیل با هوش مصنوعی» را بزنید.
5. خروجی CSV بگیرید و **قبل از اقدام، مهلت و شرایط را در صفحه رسمی بررسی کنید.**

<a id="country-images"></a>

## تصویر کشورها

کنار هر بورسیه یک تصویر از مکان معروف کشور مقصد نمایش داده می‌شود (برج ایفل برای فرانسه، بیگ‌بن برای بریتانیا، دروازه براندنبورگ برای آلمان و ...). برای موارد بدون کشور مشخص، کره زمین نمایش داده می‌شود.

برای استفاده از **عکس‌های خودتان**، فایل را با کد دوحرفی کشور در پوشه `assets/countries/` بگذارید (مثلاً `de.jpg` یا `gb.webp`). عکس همیشه بر تصویر پیش‌فرض (`.svg`) ارجحیت دارد. فقط از تصاویری استفاده کنید که مالک آن هستید یا مجوز استفاده دارند، و بعد از افزودن، برنامه را ری‌استارت کنید.

<a id="deploy"></a>

## استقرار آنلاین

گیت‌هاب فقط کد را نگه می‌دارد و خودش برنامه Streamlit را اجرا نمی‌کند. برای آنلاین کردن:

- **Streamlit Community Cloud (رایگان):** مخزن را در GitHub قرار دهید، به <share.streamlit.io> بروید، **Create app** را بزنید، مخزن و فایل `app.py` را انتخاب کنید و Deploy کنید. در نسخه عمومی کلید API شخصی خود را در Secrets نگذارید تا هر کاربر کلید خودش را وارد کند.
- **سرور شخصی (VPS):** با `streamlit run app.py --server.port 8501 --server.address 0.0.0.0` و پشت Nginx یا Caddy با HTTPS.

<a id="notes"></a>

## نکات مهم

- اطلاعات بورسیه ممکن است ناقص یا قدیمی باشد و هوش مصنوعی هم اشتباه می‌کند؛ همیشه صفحه رسمی را بررسی کنید.
- خزنده‌ها برای استفاده شخصی و سبک هستند؛ شرایط استفاده و `robots.txt` هر سایت را رعایت کنید. بعضی سایت‌ها دسترسی خودکار را رد می‌کنند (خطای 403).
- فایل‌های فونت `static/` مربوط به IRANSansX هستند؛ قبل از بازتوزیع، مجوز آن را بررسی کنید.
- اگر هنگام نصب خطای `Microsoft Visual C++ 14.0 or greater is required` یا `Failed building wheel` (برای pyarrow یا pyyaml) دیدید، نسخه Python شما خیلی جدید است (مثلاً ۳.۱۵) و پکیج آماده ندارد. Python ۳.۱۲ یا ۳.۱۳ را نصب کنید، پوشه `venv` را پاک کنید و دوباره `Run (Windows).bat` را اجرا کنید؛ اسکریپت خودش نسخه مناسب را انتخاب می‌کند. پیام `'streamlit' is not recognized` هم یعنی نصب وابستگی‌ها شکست خورده و باید خطای بالاترش را رفع کنید.
- اگر خطای `Could not open requirements file ... 'requirements.txt'` دیدید، یعنی اسکریپت اجرا کنار فایل‌های پروژه نیست (مثلاً از داخل خود ZIP اجرا شده یا از پوشه بیرون آورده شده). کل فایل ZIP را Extract All کنید و `Run (Windows).bat` را از داخل پوشه استخراج‌شده و بدون جابه‌جایی اجرا کنید. همچنین مطمئن شوید فایل `requirements.txt` در مخزن شما وجود دارد.
